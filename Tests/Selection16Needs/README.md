The compact Needs body extends `Docs/UI-Reworked/details/needs.png`; the user's actual v0.17.0 screenshot establishes the oversized native thoughts, omitted separators and horizontal scrollbar to correct. The replacement uses 20-pixel thought rows, 25-pixel need rows, the shared 11-pixel labels/10-pixel small labels, a vertical column divider, a divider below Mood, one between nonnegative/negative thought groups and one between Food/Recreation and all remaining visible needs. Nine thought rows and their polarity divider fit the normalized 195-pixel thought viewport. Positive/negative numbers retain muted semantic colors. `PawnInspectorWidgets` supplies a slim vertical rail only when content overflows; content width never exceeds the viewport, and horizontal scroll is not introduced.

`PawnNeedsUIUtility.GetThoughtGroupsInDisplayOrder`, `ThoughtHandler.GetMoodThoughts`, `GetLeadingThoughtInGroup` and `MoodOffsetOfGroup` remain authoritative for visible groups, stack members, leading labels and effects. No mood or need value is changed. Native visible needs are filtered by `Need.ShowOnNeedList` and sorted through `PawnNeedsUIUtility.SortInDisplayOrder`; Food/Recreation lead, while Sleep/Rest, Comfort and other visible needs remain accessible in native relative order. Native descriptions, alternative stacked labels, baby talk/translation, memory expiration ranges and source-precept causes remain in full tooltips. Source-precept thoughts have the cyan ideology marker with the native ideology information action. The native cannibal-ideology last-human-meat context remains a compact localized row when relevant.

Novelty dots are an explicitly **inferred session-only observation rule**, not a claimed native save property or source measurement. Each pawn's first observed thought-group snapshot is a baseline with no dots. A group first observed later, or observed absent and then present again, gets a muted novelty dot. Identity uses the native `Thought.GroupsWith` relation plus a recorded stage snapshot, preserving native stack group boundaries. Its dot clears after 417 game ticks (about ten in-game minutes) accumulated only in consecutive rendered frames where the full row is visible. Paused time, offscreen rows, a hidden tab and switching pawns do not consume this duration. `Reset()` resets scrolling/visibility only; pawn histories survive switching. A new `Current.Game` clears all session histories. Changes that occur entirely while unobserved cannot be reconstructed and are not invented. Nothing is serialized into saves.
