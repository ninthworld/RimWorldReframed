# Shared colony-menu and World integration checks

Run `dotnet run --project Tests/BottomMenuContracts/BottomMenuContracts.csproj -c Release` and Windows PowerShell `Tests/BottomMenuContracts/Test-Native.ps1 -ModAssembly <private DLL>`.

The pure suite links actual shared geometry/input policy and reversible motion. It checks supported viewport fallback, all preferred body minima, dock clearance, moving/closed/obscured/unpainted input suppression and interrupted opening/closure.

The reflection/IL suite checks each newly registered Harmony target against the runtime guard list, including normalized inherited main-tab methods. It applies the World time/date transpiler to copied instructions in memory and requires exactly one time and one date substitution with unchanged unrelated instructions/control markers. It does not install patches, create game windows, invoke native UI callbacks or operate RimWorld. Run the roster, knowledge, world and existing runtime suites separately; a build/metadata pass is not live acceptance.
